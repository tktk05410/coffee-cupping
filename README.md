# 咖啡杯测表

一个单文件、离线可用的咖啡杯测记录表。打开 `index.html` 就能填，不需要安装、不需要服务器、不联网也能用。

## 功能

- **外在评估**：种植、处理、贸易、认证与奖项，记录一支豆子的来路。
- **生豆物理评估**：颜色、类别一 / 类别二瑕疵点数（按比例自动折算）、水分。
- **描述性评估**：干香、湿香、风味、余韵、酸质、甜感、口感各自的 0–15 强度刻度，配鼻前 / 鼻后描述词与主要味道。
- **情感性评估**：八项「对品质的印象」九分制打分，可手填复核后的「最终」分。
- **自动计分**：`S = 0.65625 × Σh + 52.75 − 2u − 4d`，四舍五入到最近的 0.25 分；瑕疵杯与不一致杯按双字段规则计入。
- **多样的记录**：最多 8 个样品并列，结果汇总里有品质印象雷达图与全部样品对比。

## 使用

直接双击 `index.html`，或用任意静态服务器托管。记录自动存在浏览器的 localStorage 里，关掉页面再打开还在。

## 打印

点右上角「打印本表」，在弹窗里勾选要打印的章节（可全选），A4 纸面按「标题 + 外在 + 生豆物理」一页、描述性一页、情感性一页、结果汇总一页排布，屏幕上的说明与占位提示不会印到纸上。

## 数据

所有记录只保存在本机浏览器，不上传任何服务器，也没有统计或广告脚本。清除浏览器数据、更换设备或更换访问网址都会让已有记录不可见——重要批次请打印留存纸质件或 PDF。

## 作者备注

这张表起因是给自己杯测用，字段、分值与打印版式都按实际使用改过几轮，所以它更像一份工作稿，而不是标准答案。发现算错、想加字段或调整权重，欢迎开 Issue，或者直接把 `index.html` 拷走改。个人项目，不保证持续更新，也不提供商业支持。
